Malawakil Tokyo — Office Management System (OMS V2)
Kedutaan Besar Malaysia, Tokyo, Jepun 🇲🇾🇯🇵
Sistem pengurusan pejabat diplomatik bersepadu berasaskan web untuk Kedutaan Besar Malaysia di Tokyo.
---
🌟 Ciri-Ciri Utama
Papan Pemuka (Dashboard): Notis pekeliling rasmi, kad status eksekutif misi, analisis perbelanjaan, log audit, dan kalendar acara/tugasan diplomatik.
Pengurusan Cuti Rasmi: Jadual kalendar cuti 31 hari, semakan baki cuti tahunan, dan borang permohonan berserta aliran kelulusan pentadbir.
Direktori Pegawai & Staf: Pengurusan senarai HBS (Home-Based Staff) dan LRS (Locally Recruited Staff).
Pengurusan Baucar Kewangan: Sokongan penukaran dwi-mata wang JPY (¥) & MYR (RM) secara langsung.
Inventori & Pengurusan Aset: Penjejakan dokumen keselamatan (visa/pasport kecemasan), stok cenderahati rasmi, dan aset canseri dengan amaran stok minimum.
Pangkalan Data Google Sheets: Integrasi awan terus menggunakan Google Apps Script Web App API.

Pilih repositori ini (`malawakil-tokyo-oms`).
Kosongkan ruangan Build command dan Publish directory (kerana ia adalah aplikasi single-file HTML).
